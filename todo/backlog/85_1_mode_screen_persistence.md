# Сохранять экран выбора Library/Project при переключении вкладок

Status: ready-for-agent
Priority: 1

Слой D. Дефект найден при постановке задачи 85: переход Library → Project →
Library сбрасывает страницу выбора Library на редактор последней библиотеки.

## Проблема

`Root.SetMode` (`internal/server/interface/ui/root/root.go`) при каждом
открытии вкладки пересчитывает экран моды:

```go
if m := r.modeView(mode); m != nil && m.picker != nil {
    r.showList[mode] = r.selected[mode] == uuid.Nil
    ...
}
```

`showList` — это состояние экрана, а не выбор сущности: его ставят
`showListPage`, `openEntity`, `selectEntity` и `entityGone`. Пересчёт в
`SetMode` затирает его, поэтому человек, ушедший со страницы выбора (при уже
выбранной библиотеке), возвращается в редактор.

## Решение

- `SetMode` не трогает `showList` у уже открытой моды. Решение об экране
  принимается один раз, при первом открытии моды: `selected[mode] == uuid.Nil`
  → страница, иначе редактор (сохранённая сущность из LocalStorage, task 73).
- `showListPage`, `openEntity`, `selectEntity` и `entityGone` остаются
  единственными, кто меняет `showList` после первого открытия.
- Повторное нажатие на активную вкладку не обязано ничего менять: оно не
  сбрасывает страницу и не открывает редактор.
- `picker.Reload` при показе страницы сохраняется: страница перечитывает
  список, когда её показали (`showListPage`), и при первом открытии моды.
- LocalStorage `root:mode` не меняется. Поведение «вкладка открывает последнюю
  сущность или страницу» после перезагрузки страницы браузера остаётся: это
  отдельное правило task 73, не состояние сессии.

## Тесты

- `internal/server/interface/ui/root/selection_test.go` (или `modes_test.go`):
  - выбрать Library, открыть редактор, нажать Back → страница; перейти в
    Project; вернуться в Library → страница, а не редактор;
  - обратный случай: быть в редакторе Library, уйти в Project, вернуться →
    редактор;
  - первый показ моды с сохранённым ID в LocalStorage → редактор; без ID →
    страница;
  - `entityGone` по-прежнему показывает страницу и перечитывает список;
  - `showListPage` перечитывает picker ровно один раз.
- Ручной проход в PWA (правило 9): Library → выбрать библиотеку → Open →
  Back → Project → Library; страница выбора осталась; то же для Project.

## Документы

- В `AGENTS.md` описание режимов уже говорит, что вкладка открывает
  сущность/страницу; уточнить, что выбранный экран моды сохраняется на время
  сессии (это часть 85_8, отдельной правки здесь не нужно).

## Вне объёма

- Сохранение экрана выбора между перезагрузками браузера (сейчас после
  перезагрузки вкладка открывает последнюю сущность — правило task 73).
- Изменение вкладок Operation/History.
