# Устаревшие ответы в живой перезагрузке UI
Status: ready-for-agent

Найдено в ревью задачи 29. Все ошибки старые: рефакторинг задачи 29 перенёс их без изменений. Общая причина — ответ, запрошенный до записи, применяется после неё.

- Список, запрошенный до создания, считает новый объект удалённым. Для Tag это закрыто (`tagLists`/`tagCreated`, `project/load.go`), для остальных нет:
  - `library/load.go` `setWidgetTypes`: только что созданный WidgetType пропадает из списка, выбор и LocalStorage сбрасываются (`clearSelection`).
  - `project/load.go` `setWidgets`: при быстром добавлении двух виджетов со второго снимается выбор.
  - `project/load.go` `setScenes`: только что созданная Scene пропадает, выбор переходит на `scenes[0]`.
  - Кандидат на общее решение — `uiutil.Versions`: ID, учтённый через `Observe` после `Mark` списка, не считается удалённым из-за того, что его нет в этом списке. Заменил бы `tagLists`/`tagCreated`.
- Library не защищена от списка, запрошенного до переименования (у Scene это делает `sceneStates.Advance`): слияние откатывает имя в списке и в редакторе, следующий Apply молча отправляет старое имя.
- `project/widget_ops.go` `finalizeAllDrags`: отложенный `loadWidgets` идёт одновременно с PUT перетаскивания. Если GET выполнится раньше, виджет прыгнет на старое место до `widget_updated`.
- `project/load.go` `setScenes`: когда выбранную Scene удаляют и выбор переходит на другую, `p.widgets` не очищается. Виджеты удалённой сцены рисуются на холсте другой, их правка даёт 404. Если сцен не осталось, `p.widgets` остаётся устаревшим. То же в `selectScene` до ответа.
- `project/scene_versions.go` `loadStaleScenes`: `staleScenes` очищается до GET. После сетевой ошибки повтора нет, следующая правка этой Scene получает ложный 409.
- `project/edit_fields.go` `widgetEditFieldsOf` округляет геометрию (`%.1f`, `%.3f`), а `saveWidgetGeometry` разбирает текст редактора. Сохранение из панели округляет и поля, которых пользователь не трогал (поворот 37.2846 → 37.3).

## Решения

- Список, запрошенный до создания: общий механизм в `uiutil.Versions`. Если ID учтён через `Observe` после `Mark` списка, отсутствие ID в этом списке не значит, что объект удалён. Применить к WidgetType, Widget, Scene и Tag; `tagLists`/`tagCreated` удалить.
- Library: `setWidgetTypes` через `l.versions.Advance`, как `setScenes` через `sceneStates.Advance`: элемент списка берётся, только если его версия новее известной, иначе остаётся локальный. Второй `Versions` не нужен: у WidgetType версия записи совпадает с версией состояния.
- Перетаскивание: если `finalizeAllDrags` отправил PUT, отложенный `loadWidgets` не запускается. Список перечитает `widget_updated` этой записи после коммита, а при 409 его перечитает `rejectedSceneEdit`. Если PUT не отправлялся, загрузка запускается сразу, как сейчас.
- Смена выбранной Scene (удалили выбранную, `selectScene`, сцен не осталось): `p.widgets` очищается в одном месте вместе со снятием выбора виджета, и до ответа `loadWidgets` на холсте показывается индикатор загрузки.
- `loadStaleScenes`: при ошибке GET (кроме 404) ID возвращается в `staleScenes` и перечитывается при следующей загрузке. Таймеров повтора нет.
- Округление: в `saveWidgetGeometry` поле, чей текст равен `widgetEditFieldsOf(текущий виджет)`, отправляется точным значением из виджета, иначе разобранным текстом. Отображение не меняется.
