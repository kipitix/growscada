# EditLock

Type: task

- Acquire/Release блокировки проекта Engineer'ом; без EditLock режим Project только для чтения (UI и сервер отклоняют правки Draft).
- Привязка к SSE-подключению Client; после отключения — снятие по таймауту (константа, ~5 мин).
- Принудительный перехват другим Engineer с подтверждением; прежний держатель получает уведомление и переходит в read-only.
- Факт редактирования индицируется всем клиентам (кто держит, с какого времени).
- Release не сбрасывает Draft и стек undo.
