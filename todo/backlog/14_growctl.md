# growctl

Утилита для декларативного управления сущностями (в первую очередь тегами) через YAML-манифесты, по аналогии с `kubectl apply` — нужна для быстрого поднятия тестовых окружений без миграций через goose. Используется симулятором нижнего уровня для сидирования тестовых тегов. Детальная проработка (какие сущности поддерживает, синтаксис манифеста, diff/apply-семантика) — отдельная задача.
