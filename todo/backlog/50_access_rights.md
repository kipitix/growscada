# Права доступа
Priority: 3
Blocked by: 34, 49

- Разграничение пользователей и устройств
- Для пользователей авторизация через внешние системы
- Права пользователей в Organization и Project (кто может Save, Deploy, Rollback, Import, управлять лейблами и назначать их)
- Устройства авторизуются Device Token (задача 34)

## Comments

- 2026-10-25 (grilling задачи 31): на общем сервере у Project один владелец-Organization (интегратор или завод), вторая сторона работает в нём через права доступа. Решить, кто владелец по умолчанию и как приглашается участник из другой Organization.
- 2026-10-27 (grilling задачи 33): доступ к Library. Пока любой Project сервера импортирует сохранённое состояние любой Library; здесь — кто и чьи Library видит (публичность через Organization), и инварианты при смене прав доступа к Library, уже импортированной в проекты (как удаление импортированной Library, ADR 0012).
- 2026-11-15: сверено с кодом после цепочки 85. Термины обновлены: Import — импорт сохранённого состояния Library, Release больше нет; лейблы — `engineering.labels` и назначения `engineering.commit_labels` уровня Organization (ADR 0025). Задача 34 закрыта, зависимость остаётся только от 49.
