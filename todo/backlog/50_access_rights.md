# Права доступа
Blocked by: 34, 49

- Разграничение пользователей и устройств
- Для пользователей авторизация через внешние системы
- Права пользователей в Organization и Project (кто может Deploy, Release, Rollback)
- Устройства авторизуются Device Token (задача 34)

## Comments

- 2026-10-25 (grilling задачи 31): на общем сервере у Project один владелец-Organization (интегратор или завод), вторая сторона работает в нём через права доступа. Решить, кто владелец по умолчанию и как приглашается участник из другой Organization.
- 2026-10-27 (grilling задачи 33): доступ к Library. Пока любой Project сервера закрепляет релизы любой Library; здесь — кто и чьи Library видит (публичность через Organization), и инварианты при смене прав доступа к Library, уже закреплённой в проектах (как удаление закреплённой Library, ADR 0012).
