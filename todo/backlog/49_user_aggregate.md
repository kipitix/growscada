# Агрегат User
Priority: 3

- User — член Organization (задача 31); Projects и Libraries принадлежат Organization, а не User.
- User — идентичность, на которую опираются права доступа (задача 50): сегодня права не различают людей, а Device Token различает устройства (задача 34).

Эта задача даёт агрегат и членство в Organization, а не расширение аудита.
- EditLock убран (72_1), поэтому «держателя замка» больше нет.
