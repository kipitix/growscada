# Русская подпись `← Список` в PWA: весь интерфейс на английском

Status: ready-for-agent
Priority: 1

Найдено при ревью задачи 73. Весь интерфейс PWA английский («Projects»,
«Libraries», «Open», «Edit», «Save», «Discard»), а слим-строка возврата к
странице выбора — русская: `root.go:656` `label := "← Список"` (и
`← Список · <name>`). Других пользовательских неанглийских строк в UI нет:
`grep` по кириллице в `internal/server/interface/ui` находит только её (и
упоминания в комментариях `root.go:57,652`, `picker/picker.go:5`).

## Задача

Привести подпись к английскому и закрепить это проверкой.

## Что меняется

- `internal/server/interface/ui/root/root.go`: `label := "← List"` (строка
  показывает также имя сущности: `← List · <name>`); комментарии
  `renderBackBar`, поля `entityName` и `OnMount` — на новый текст.
- `internal/server/interface/ui/picker/picker.go:5` — комментарий со ссылкой на
  строку.
- `internal/server/interface/ui/root/selection_test.go:86,90` — литералы
  `"← Список · Main"` / `"← Список"` заменяются на новые.
- Прочёсывание UI на кириллицу (`grep -rn "[А-Яа-яЁё]" --include=*.go
  internal/server/interface/ui`, исключая комментарии): новых
  пользовательских строк быть не должно; найденные — сюда же.

## Приёмка

1. В шапке редактора Library и Project читается `← List` и `← List · <имя>`;
   клик по-прежнему показывает страницу выбора, сущность остаётся объявленной
   потоку событий.
2. Во всём UI нет пользовательских строк на русском (проверка `grep` из задачи
   плюс осмотр в браузере).
3. `make build`, `make test` зелёные; `selection_test.go` обновлён. Контракт и
   REST не меняются — Bruno не трогаем.
