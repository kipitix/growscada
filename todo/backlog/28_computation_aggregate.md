# Агрегат ComputationType и Computation

- Computation - некое вычисление, производимое на сервере
- Цель - сделать обработку и формирование новых тегов (например из нескольких значений сформировать одно)
- Нужна работа со временем (таймеры)
- Нужно срабатывание по таймеру или по изменению одно из тегов, из которых формируется значение
- Нужна возможность помнить некоторые состояния между вызовами
- Нужна возможность обрабатывать команды от пользователя
