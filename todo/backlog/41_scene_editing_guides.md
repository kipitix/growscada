# Направляющие при редактировании сцен

Status: ready-for-agent

Слой C.

## Цель

Холст Project остаётся читаемым на любой Scene, а расстановка виджетов получает направляющие выравнивания со snapping. Всё — только клиент (WASM UI): сервер, контракты `contract/` и домен не меняются.

## Сетка

- Сетка — редакторский слой `renderCanvasGrid()` (`project/render_scene.go`) между фоном Scene и виджетами; шаг 24 px не меняется.
- Точка двухцветная: светлое ядро радиусом 1 px и тёмное кольцо примерно до 1.75 px (два `radial-gradient` в одном `background-image`). На любом фоне хотя бы одна часть точки контрастирует; на тёмном видно ядро, на светлом — кольцо.
- Сетка не зависит от темы: `--dot-color` убирается из обеих тем (`root/root.go`), цвета точки задаются в `renderCanvasGrid()`.
- В Operation сетки нет — она остаётся принадлежностью редактора.

## Направляющие и snapping

- Работают только при перетаскивании тела виджета (ветка `draggingWidgetID` в `project.go`), для одного виджета и для группы. Ресайз, поворот, перенос origin, стрелки, правка координат в панели свойств и создание виджета из палитры идут без направляющих.
- Цели — края и центры (лево/центр/право, верх/середина/низ) axis-aligned bounds других виджетов текущей Scene плюс края и центр Scene: `0`, `width/2`, `width`; `0`, `height/2`, `height` (при нулевых размерах — 1920×1080, как у холста).
- Выбранные виджеты целями не являются.
- Для группы считается общий axis-aligned bounding box выборки (объединение `widgetBounds` каждого выбранного), притягивается он, и весь дельт группы корректируется одним смещением.
- Порог — 6 px, притяжение жёсткое, по каждой оси независимо. Побеждает ближайшая цель; при равенстве расстояний — цель Scene. Свободная ось не округляется, позиции остаются `float64`.
- Пока притяжение активно, рисуются направляющие: 1 px сплошная `var(--accent)` во всю ширину/высоту холста, слоем над виджетами и под рамкой выделения, `pointer-events: none`; не более одной вертикальной и одной горизонтальной линии. После отпускания линии исчезают.
- Alt/Option во время перетаскивания отключает snapping и прячет направляющие; позиция при этом пересчитывается от старта перетаскивания, как сейчас. Отпускание Alt возвращает притяжение.
- Итог перетаскивания — тот же один `PATCH …/scenes/{id}/widgets` (ADR 0010, ADR 0016), только с притянутыми координатами: новых DraftChange, событий и полей API нет.

## Реализация

- Геометрия — чистые функции рядом с `widgetBounds` в `ui/project/marquee.go`: сбор целей, выбор ближайшей на ось, смещение выборки и координаты линий. Без DOM, чтобы покрыть табличными юнит-тестами.
- Состояние перетаскивания (клиентские координаты, стартовые позиции) уже есть; направляющие — поле состояния `Project`, сбрасываемое в `finalizeAllDrags`.
- Слой направляющих добавляется в `canvasLayers()` после виджетов и перед рамкой выделения.
- `AGENTS.md` (раздел PWA UI, Project) дополняется: сетка не зависит от темы, направляющие и притяжение 6 px работают при перемещении одного виджета и группы (общий AABB), Alt отключает притяжение.

## Тесты

- Юнит: притяжение края к краю и к центру другого виджета; к краям и центру Scene; отсутствие притяжения за пределами 6 px; повёрнутый виджет по AABB; группа по общему AABB; Alt отключает притяжение; равенство расстояний выбирает цель Scene.
- UI (`uitest`/`TestEngine`): во время перетаскивания с притяжением в дереве есть слой направляющих, после mouseup его нет, позиция виджета притянута.
- Существующие тесты перетаскивания, выбора и `widgetBounds` остаются зелёными.

## Приёмка

- `make full_restart`, Project → Main Dashboard и Overview Panel, светлая и тёмная темы: сетка видна на тёмном фоне.
- Перетаскивание одиночного виджета и группы: линии появляются у краёв/центров соседей и Scene, позиция притягивается; Alt — свободное движение; после отпускания линии исчезают и уходит один PATCH.
- `make build`, `make test`; `make bruno_test` — API не менялся, коллекции остаются как есть.
