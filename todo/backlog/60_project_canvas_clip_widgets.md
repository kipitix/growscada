# Обрезать виджеты по краю Scene на холсте Project
Status: needs-triage

Появилось на код-ревью задачи 27. Холст Operation (`livescene.View`) обрезает всё по краю Scene (`overflow: hidden`), а холст Project (`project/render_scene.go`, `renderSceneCanvas`) — нет. Виджет, частично вынесенный за край Scene, в Project рисуется целиком поверх `var(--bg-inset)` вокруг холста, а в Operation обрезан по краю фона. Engineer снова не видит то, что увидит Operator.

- Содержимое виджетов (iframe превью) на холсте Project обрезается по краю Scene, как в Operation.
- Ручки выделенного виджета (якорь origin, поворот, resize) не обрезаются: остаются видны и работают и за краем Scene — иначе виджет у края нельзя ни повернуть, ни уменьшить. `overflow: hidden` на сам холст поэтому не подходит: обрезать только слой виджетов (`uiutil.SceneWidgetLayer`), а ручки рисовать отдельным слоем поверх, не обрезанным.
- Часть виджета за краем Scene можно как-то обозначить (например, контур рамки выделения за краем), чтобы виджет за краем можно было найти и схватить. Решить при triage.
- Drag-and-drop типа виджета на холст, клик по пустому месту, drag/resize/rotate виджетов работают как раньше; `z-index: Position.Z` виджетов сохраняется.

## Приёмка

- Виджет, вынесенный за правый/нижний край Scene, в Project обрезан по краю так же, как в Operation; у выделенного такого виджета ручки видны за краем и работают.
