# Смена поставщика у Tag'а

Status: needs-info
Blocked by: 66

Поставщик Tag'а — часть его определения (`tag.Supplier`, `id.ID[device.Device]`), но задаётся только при создании и восстановлении: у `Tag` нет мутации, а `tag_updated` занят состоянием (ADR 0011). Спека задачи 34 (часть A, «Связь с Tag»): «поставщик не может измениться без версии — смена поставщика обычная мутация Tag'а, ожидающая версию».

## Что сделать

- `Tag.ChangeSupplier(expected version.Version[Tag], aSupplier Supplier) (Tag, error)`: проверка версии, возврат нового Tag'а, запись события определения.
- Новый тип события `tag_definition_updated` (или имя, согласованное с ADR 0009): четыре правки — `event.EventType*`, `apiv0.EventTypes()`, `restapi.apiEventTypes`, образец в `samples`; подъём SchemaVersion контракта и `make schemas`.
- Кодек outbox, маппинг журнала UI, `ReloadTargetsFor` (событие делает устаревшим список Tag'ов).
- Bruno: запрос на смену поставщика, если REST появится в этой же задаче.

## Почему отложено

API привязки Tag→Device ещё не спроектирован (задача 66/часть 4): неизвестно, приходит ли поставщик в `CreateTagRequest`/`PutTagRequest`, и нужен ли отдельный эндпоинт. Делать мутацию сейчас — значит угадывать форму API и завести событие, которого никто не публикует.
