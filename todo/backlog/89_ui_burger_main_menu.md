# UI: главное меню — бургер и строка навигации вместо вкладок

Status: ready-for-agent
Priority: 1

Главное меню приложения вместо четырёх вкладок сверху: бургер-кнопка и строка навигации на той
же строке, выбор режима и сущности — в выпадающем меню. Запрос — 2026-11-15, решения гриля —
тогда же.

## Верхняя строка

- **Вкладок нет**: `Root.Render` (`internal/server/interface/ui/root/root.go`) не рисует
  `role="tablist"` и `r.tab("Library"|"Project"|"Operation"|"History")`; `Mode`, `SetMode`,
  `root:mode` и ленивое монтирование режимов остаются.
- **Бургер слева**: `<button>` с `aria-label="Main menu"`, `aria-haspopup`, `aria-expanded`
  и `aria-controls`; клик открывает и закрывает меню.
- **Строка навигации на той же строке**, справа от бургера: `Режим · Сущность`, разделитель —
  `·` (`U+00B7`, MIDDLE DOT, точка по середине высоты символа). Примеры: `Library · Greenhouse`,
  `Project · Greenhouse v2`, `Operation · Greenhouse`, `History · Greenhouse`. На странице выбора
  сущности — только режим (`Library`, `Project`); у Operation и History проекта нет — тоже только
  режим. Имя берётся из режима, когда тот загрузил содержимое; пока не известно — только режим
  (без кэша имени в LocalStorage). Строка кликабельна и открывает меню на текущем режиме;
  на узком экране обрезается многоточием, полный текст — в `title`.
- **Справа** прежние кнопки: Labels и переключатель темы.
- На телефоне верхняя строка остаётся одной; меню раскрывается на всю ширину.

## Главное меню

- **Выпадающая панель** под верхней строкой у левого края, поверх содержимого, без затемнения.
- **Закрывается** кликом вне, `Esc` (фокус возвращается на бургер), повторным кликом по
  бургеру/навигации и любым выбором пункта.
- **Четыре строки режимов** (`Library`, `Project`, `Operation`, `History`) в аккордеоне:
  текущий режим раскрыт сразу и проскроллен к текущей сущности. Клик по строке режима только
  раскрывает/сворачивает его — режим переключается выбором пункта внутри.
- **Внутри раскрытого режима**:
  - Library — `Choose a library…` и список библиотек;
  - Project — `Choose a project…` и список проектов;
  - Operation и History — только список проектов: у них нет страницы выбора.
- **Строка сущности** — имя и тот же бейдж состояния, что на странице выбора (`picker.Item.State`,
  `StateKind`: unsaved changes / saved / never saved); текущая отмечена галочкой и `aria-checked`.
  Порядок — как на странице выбора: библиотеки в порядке инженера (ADR 0024), проекты по имени.
  Список прокручивается в своей высоте; поиска и фильтра нет.
- **`Choose a library…` / `Choose a project…`** переключает режим и показывает его страницу выбора
  (`showListPage`), перечитывая список.
- **Конкретная библиотека или проект** открывает редактор сразу (`openEntity`), меню закрывается;
  страница выбора показывает ту же сущность выбранной и того же требует поток событий.
- **Operation и History** получают проект из меню: выбор строки проекта сохраняет его под
  `<mode>:projectID`, переключает режим и отдаёт проект режиму. Селект `projects.Switcher` над
  содержимым убирается, пакет `projects` удаляется вместе с тестами, если других пользователей
  не останется.
- **Списки читаются при каждом открытии меню** и обновляются событиями `library_*` / `project_*`,
  пока меню открыто (свои чтения, независимо от того, открывался ли режим).
- **Нет проектов вовсе**: строки Operation и History неактивны с подсказкой `No projects yet`.
- **Пустые списки**: `No libraries yet` / `No projects yet`; пункт `Choose …` остаётся — создание
  живёт на странице выбора.
- **Выбранный проект удалён** (`project_deleted`, `uiutil.ActionProjectGone`): выбор сбрасывается,
  а не подменяется первым; режим остаётся показанным с пустым состоянием `Choose a project in the
  main menu`, навигация — только режим.
- **Ничего не теряется**: меню переключает режимы так же, как вкладки, — без размонтирования,
  незасохранённые правки Draft и iframes остаются. Повторный выбор текущей сущности ничего не
  перезагружает.

## Доступность

Disclosure-паттерн, без стрелок и typeahead: бургер и строки режимов — `<button>` с
`aria-expanded`; строки сущностей — `role="menuitemradio"` с `aria-checked`; панель — контейнер
с `aria-label="Main menu"`; `Esc` закрывает и возвращает фокус бургеру; `Tab` обходит пункты.

## Не входит

Поиск по спискам, создание библиотеки/проекта из меню, изменение Labels и темы, URL-маршруты,
функциональность History (остаётся заглушкой), API и Bruno (API не меняется).

## Приёмка

- В PWA нет верхних вкладок: режим и сущность выбираются из главного меню.
- Строка навигации показывает `Режим · Сущность` с `·`; на странице выбора и без проекта — только
  режим; обрезается на узком экране.
- Из меню достижимы: страница выбора библиотек, конкретная библиотека, страница выбора проектов,
  конкретный проект; для Operation и History — конкретный проект.
- Списки в меню свежие при открытии, следуют событиям, показывают бейджи состояния, длинный
  список прокручивается.
- Оставлены: возврат из редактора к странице выбора (задача 84), сохранённый экран режима
  (85_1), обработка ушедшей сущности (76), `Esc`/клик вне закрывают меню, фокус возвращается.
- Тесты: новые тесты меню и навигации рядом с `root/modes_test.go`, `root/projects_test.go`;
  обновлены тесты, которые опирались на вкладки и `projects.Switcher`.
- `docs/architecture/interface.md`: описание вкладок, `projects.Switcher` и верхней строки
  приведено к меню.
- `make build`, `make test`, `make bruno_test` проходят; консоль браузера без ошибок.

## Связанное

- `internal/server/interface/ui/root/root.go` — `Mode`, `SetMode`, `tab`, `Render`, `modeSlot`,
  `modeContent`, `selectEntity`, `openEntity`, `showListPage`, `entityGone`.
- `internal/server/interface/ui/picker/` — страницы выбора, `picker.Source`/`Item` и бейджи
  состояния, которые меню переиспользует.
- `internal/server/interface/ui/projects/switcher.go` — убираемый селект проекта.
- Задачи 84 (возврат из редактора), 76 (сущность ушла), 85_1 (сохранённый экран режима),
  82 (бейджи состояния на странице выбора), 81 (порядок библиотек).
