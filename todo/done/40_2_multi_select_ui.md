Часть 2 задачи 40. Источник истины — `todo/backlog/40_multi_select_move_objects.md`; здесь UI Project-режима. Маршрут `PATCH …/scenes/{scene_id}/widgets` готов в 40_1.

**За рамками:** серверная часть (40_1); групповые поворот, масштаб, удаление, копирование и вставка; выделение Scene в списке.

## Состояние выделения

- Вместо одиночного `selectedWidgetID` — упорядоченный набор `selectedWidgetIDs []uuid.UUID`; ведущий (primary) — последний элемент. Хелперы: `isWidgetSelected`, `primaryWidgetID`, `selectOnly`, `selectWidgets`, `toggleWidgetSelection`, `addToSelection`, `clearWidgetSelection`, `pruneSelection`.
- В LocalStorage под `selectionKey(widgetIDKey)` по-прежнему лежит только ведущий ID: после перезагрузки выделен один виджет. `restoreSelection` восстанавливает его одного.
- `SetProject` и `selectScene` снимают выделение целиком; `setWidgets` после перечитывания отбрасывает ID, которых больше нет, и переносит ведущего на последний оставшийся.
- `widgetEdit` синхронизируется только при ровно одном выбранном; при нуле или нескольких — пустые поля. `selectedWidgetIdx()` возвращает индекс только при ровно одном выбранном, иначе −1: правки из панели (имя, геометрия, привязки, удаление) при группе не действуют.

## Жесты

- Клик по виджету без модификатора — заменить выделение им.
- Shift/Ctrl(Cmd)+клик (или mousedown с модификатором) — добавить или убрать, без начала перетаскивания.
- Клик по пустому месту холста — снять выделение (как сейчас).
- Рамка: mousedown на пустом месте холста (левая кнопка, без модификатора) задаёт начало, движение по корневому div режима обновляет прямоугольник, mouseup завершает. Рамка заменяет выделение; Shift+рамка добавляет. Протяжка меньше 3 px по обеим осям — это клик.
- Ctrl/Cmd+A — все виджеты текущей Scene; Esc — снять выделение (и отменить начатую рамку). Оба игнорируются в поле ввода (`uiutil.KeyEventTyping`), при открытом диалоге режима (`keyActionAllowed`) и когда режим не показан (`shown`).
- Read-only: выделение, рамка и Ctrl+A работают; перетаскивание и стрелки — нет. Клик по виджету в read-only больше не показывает toast: подсказка read-only и так в строке замка; toast остаётся у попыток записи (удаление, панель, стрелки).

## Рамка

- Прямоугольник рисуется в координатах холста (холст не масштабируется): полупрозрачная заливка и пунктирная рамка цвета `var(--accent)`, `pointer-events: none`, поверх слоя виджетов.
- Виджет попадает в рамку по пересечению axis-aligned bounding box. BBox считается из матрицы трансформации: четыре угла `(0,0)…(w,h)` прогоняются через `A…F`, берутся min/max по x и y — поворот учитывается.
- Порядок выделения — порядок `p.widgets`; ведущий — последний попавший.

## Перетаскивание

- Mousedown на невыделенном виджете без модификатора — `selectOnly` им, затем перенос только его; на выделенном — перенос всей группы.
- В начале переноса запоминаются стартовые позиции всех выделенных; на mousemove каждому ставится `start + (dx, dy)`. Кламп к границам холста не делается (как и сейчас), поворот виджета на дельту не влияет — позиции абсолютные в координатах холста.
- Панель свойств обновляет поля только при ровно одном выбранном; ручки якоря/поворота/масштаба видны и работают только при ровно одном выбранном.
- Завершение (`finalizeAllDrags`) всегда шлёт один PATCH со всеми выделенными, чья позиция отличается от стартовой, — и для одного виджета тоже. Если отличий нет (клик или возврат на старт), запроса нет.
- Ответ обновляет Version через `observeDraftVersion`; 409/404 обрабатывает существующий `rejectedSceneEdit` (перечитать виджеты, забыть Version). Правка геометрии из панели остаётся на `PUT …/widgets/{id}`.
- Отложенный `loadWidgets` во время взаимодействия сохраняется: `isInteracting()` истинно, пока идёт перенос или пока серия стрелок не сброшена.

## Стрелки

- Стрелка двигает все выделенные виджеты на 1 px, Shift+стрелка — на 10 px. Движение локальное и сразу видно на холсте; `preventDefault`, чтобы страница не прокручивалась.
- Серия заканчивается по keyup стрелки или через 500 мс без нажатий; тогда уходит один PATCH с текущими позициями выделенных. Таймер сбрасывается на каждом нажатии и отменяется при сбросе; реализация таймера — на усмотрение (например, `time.AfterFunc` с `Dispatch` или `window.setTimeout`).
- Любая другая запись Draft (удаление, панель, undo/redo, Deploy, Check in, смена Scene/Project, начало переноса) сначала завершает серию и только после ответа PATCH отправляет свою запись — две записи не спорят за одну Version.
- Read-only: стрелки ничего не делают (без toast на каждое нажатие).
- Потеря фокуса окна — тоже сброс серии.

## Панель свойств

- Ровно один выбранный — всё как сейчас: имя, позиция, размер, origin, поворот, привязки, удаление.
- Несколько — заголовок «N widgets selected», без редакторов и без кнопки удаления; поля сцены в этот момент не показываются.
- Ни одного — свойства сцены, как сейчас.

## События и версия

- Один перенос даёт N `widget_updated`; `uiutil.Reloader` уже склеивает перечитывание, лишний GET — не больше одного. После `setWidgets` выделение чистится от исчезнувших ID.
- `EventResync`/`EventProjectResync` перечитывают содержимое; выделение остаётся, пока ID существуют.
- Одна Version Draft на Draft (`draftVersions`) не меняется: PATCH обновляет её тем же `observeDraftVersion`.

## Тесты

- Выделение: клик, toggle, Shift/Ctrl, Ctrl+A, Esc, снятие по пустому, перенос ведущего при удалении выбранного, чистка после `setWidgets`.
- Рамка: пересечение и полное вхождение, повёрнутый виджет, Shift-добавление, протяжка меньше порога — клик.
- Перенос: группа едет на одну дельту, уходит ровно один PATCH со всеми позициями; одиночный перенос тоже PATCH; возврат на старт — запроса нет; read-only — запроса нет.
- Стрелки: 1 px и Shift 10 px, один PATCH на серию (keyup и таймер), сброс перед другой записью.
- Панель свойств: редакторы при одном, сводка при нескольких, ручки только при одном.
- Событие `widget_updated` об удалённом виджете убирает его из выделения.
- Существующие тесты (`project/drag_test.go`, `ops_test.go`) обновляются под PATCH одиночного переноса.
- `make build`, `make test`, обход режима в браузере через `chrome-devtools` (выделение, рамка, перенос, стрелки, read-only, консоль без ошибок), затем `make bruno_test` (правило 9).
