# Протокол между клиентом и сервером для передачи состояний

- Нужно организовать протокол между клиентом и сервером для передачи событий, произошедших в предметной области.
- Должно использоваться SSE как основа протокола.
- Для каждого клиента должно быть отдельное соединение.
- В будущем возможно потребуется организовать права доступа для пользователей и событий, но пока это всё единый канал событий.
- В клиенте должна быть возможность просмотра лога событий сервера, для этого нужно сделать строку состояния с отображением текущего времени и кнопкой и надписью Events, которая должна открывать и закрывать лог событий сервера внизу окна под всеми виджетами. В логе должно быть время и описание события. Последние события вверху. Лимит событий должен быть указан константой в коде клиента.
- На сервере источник событий это EventBus.
