# Выделение и перемещение нескольких объектов на Project

Status: ready-for-agent
Parts: 40_1_move_widgets_api, 40_2_multi_select_ui
Blocked by: 38

Слой C. Термины — `GLOSSARY.md` (Widget, Scene, Draft, DraftChange, Version, EditLock). Решения — ADR 0010, ADR 0016, ADR 0017; новых ADR нет.

**Это спецификация, не тикет.** Работа разбита на две части: сервер (40_1) и UI (40_2); каждая самодостаточна и проверяема, вторая блокирована первой. Источник истины — этот файл.

## Что входит

- Объекты — Widget одной Scene в Project-режиме. Список Scene сбоку — не объект выделения; групповые поворот, масштаб, удаление, копирование и вставка в задачу не входят.
- Выделение: клик, Shift/Ctrl(Cmd)+клик, рамка (пересечение), Shift+рамка, Ctrl/Cmd+A, Esc, клик по пустому месту.
- Перенос: перетаскивание мышью и стрелки (1 px, Shift — 10 px).
- Один перенос — одна DraftChange, будь это один виджет или группа; серия нажатий стрелок — тоже одна DraftChange.

## Модель

### Домен: `Scene.MoveWidgets`

- `moves` — список пар «ID виджета + новая Position». Метод проверяет каждый ID как виджет этой Scene (`ErrWidgetNotFound`), повтор ID — `ErrWidgetMovedTwice`, и строит новые Widget, меняя только `Position.X/Y`: имя, размер, origin, поворот, WidgetType, метки и PortBindings сохраняются.
- `z` не меняется: перенос не переупорядочивает слои.
- На каждый фактически сдвинутый виджет — `WidgetUpdatedEvent`; виджет, чья позиция уже равна запрошенной, пропускается без снимка и события.
- Если не сдвинулся ни один — `ErrNothingToMove`; транзакция откатывается, DraftChange и Version не появляются.
- Привязки и WidgetType не перепроверяются: сломанный биндинг не может отказать в переносе (ADR 0010). `TagTypes` и закреплённый релиз не читаются.

### Application и Draft

- `SceneService.MoveWidgets(ctx, projectID, sceneID, version, moves)` проверяет live Project и Organization (как остальное содержимое), Version Draft'а, пустой список и повторы (invalid input, 400) и одной транзакцией через `Session.MoveWidgets` пишет before/after снимки каждого сдвинутого виджета, одну DraftChange с описанием «Move N widgets» (N — число записей в `moves`) и события в outbox. Возвращает новую Version.
- `Session.MoveWidgets` загружает Scene один раз, снимает before каждого запрошенного виджета, вызывает `Scene.MoveWidgets` и пишет after каждого сдвинутого; ошибка домена откатывает транзакцию репозитория.
- EditLock, `X-GrowSCADA-Client`, `draft_conflict` и `edit_lock` — общий гейт записи Draft (ADR 0015/0016), ничего нового.
- Ошибки: `ErrNothingToMove` → 409 `nothing_to_move`; `ErrWidgetMovedTwice` → 400 (invalid input); `ErrWidgetNotFound` → 404.

### REST

- `PATCH /api/v0/projects/{project_id}/scenes/{scene_id}/widgets`, тело `{version, moves: [{widget_id, x, y}]}`, ответ 200 `{version}`.
- Строгий decode; незнакомое поле, пустой `moves` или повтор `widget_id` — 400; виджет не из Scene — 404; устаревшая Version — 409 `draft_conflict`; ни одной изменённой позиции — 409 `nothing_to_move`; всё или ничего.
- Контракт `api/v0` — MINOR (0.19 → 0.20) и `make schemas`; `project/v0` и его схемы не меняются — Position там уже есть. Новых событий нет: перенос публикует существующий `widget_updated`.

### UI

- Выделение — упорядоченный набор ID; ведущий (primary) — последний выбранный. В LocalStorage, как и раньше, хранится только ведущий: после перезагрузки выделен один виджет. Смена Scene или Project снимает выделение; исчезнувшие из списка ID отбрасываются.
- Жесты: клик заменяет выделение; Shift/Ctrl(Cmd)+клик добавляет или убирает без перетаскивания; рамка с пустого места заменяет, Shift+рамка добавляет; Ctrl/Cmd+A выделяет все виджеты Scene; Esc и клик по пустому снимают. Range-выделения по z-порядку нет: на холсте он не виден.
- Рамка ловит виджеты по пересечению axis-aligned bounding box, посчитанного из матрицы трансформации (с учётом поворота).
- Панель свойств: ровно один выбранный — всё как сейчас, включая ручки якоря/поворота/масштаба и удаление; несколько — заголовок «N widgets selected» и никаких редакторов; ручки — только у одиночного выбора.
- Перетаскивание: нажатие на невыделенный виджет без модификатора заменяет выделение им и начинает перенос; на выделенный — переносит всю группу на один dx/dy. Без клампа к границам холста. Завершение всегда шлёт один PATCH, в том числе для одного виджета; если группа вернулась на старт, запроса нет. Панель свойств по-прежнему сохраняет правку одного виджета через PUT.
- Стрелки: 1 px, Shift — 10 px; двигают локально, PATCH уходит по keyup стрелки или через 500 мс без нажатий; любая другая запись Draft сначала сбрасывает серию и не стартует, пока сброс не завершён; одна серия — одна DraftChange.
- Read-only (нет EditLock): выделение, рамка и Ctrl+A работают, перенос мышью и стрелками — нет, с обычной подсказкой read-only.
- События: один перенос даёт N `widget_updated`; `uiutil.Reloader` уже склеивает перечитывание списка, поэтому всплеск стоит не больше одного лишнего GET. После перечитывания выделение чистится от исчезнувших ID, ведущий переезжает на последний оставшийся.
