# «Saved state» вместо «commit», панель иконок и отдельный экран истории

Status: done
Priority: 2
Blocked by: 82, 83

Просьба после проверки задач 82–83: слово **commit** в интерфейсе заменить на
**saved state** (в домене — «при необходимости»); кнопка **History** должна
открывать отдельное окно со списком сохранений; внутри каждого режима —
панель с иконками наверху. Режим библиотек: назад к выбору библиотеки,
сохранить, undo, redo; **Discard** и **Revert** убрать. В истории: список с
прокруткой, в строке — время сохранения, название, автор; в конце строки —
кнопки «загрузить сохранение» (в черновик) и «назначить сохранение релизом»;
название правится.

## Что сделано

### Терминология

- В UI везде «saved state»: панель, экран истории, диалоги, тосты, статусы
  («Saved state 3 · unsaved changes», «unpublished saved state»), подписи
  пикера, строки журнала событий (`commit_created` → «Saved state 3 saved»).
- Домен, таблицы и REST API остаются `Commit` (`/commits`, `commit_created`,
  `commit_number`): это одно понятие с двумя именами, и `GLOSSARY.md` теперь
  так и говорит (новый термин **Saved state**, ссылка из **Commit**).
  Поправка в ADR 0021 от 2026-11-13.

### Загрузка сохранения в черновик

- `POST …/commits/{n}/load` для Project и Library: содержимое Commit'а
  становится Draft'ом одной транзакцией (`DiscardService.Load`,
  `LibraryService.LoadCommit`). Стек DraftChange очищается, версия
  поднимается, DraftChange не пишется; Draft чист ровно тогда, когда загружен
  последний Commit; пины, которых нет на сервере, отбрасываются с
  предупреждениями (задача 71).
- Ответ `{version, has_unsaved_changes, warnings?}`, версия не передаётся —
  это сброс, а не запись контента; 404 `commit_not_found`.
- Контракт `api/v0` MINOR 0.36, `make schemas`, `apiclient`.

### Панель режимов

- Иконки с подсказками (inline SVG, `uiutil.PanelButton`, 28×28): назад к
  выбору с именем сущности, Save (с индикатором несохранённых правок), Undo,
  Redo, History, Releases; у Project — ещё Project file, Deployments, Deploy.
  Строка состояния и автор остались текстом. `Root` отдаёт режиму `OnBack` и
  `BackName`, прежняя строка `← List · <name>` удалена.
- **Discard** и **Revert** убраны из обоих режимов; маршруты, сервисы и их
  тесты остались.

### Экран истории

- History — отдельный экран внутри режима, а не диалог: шапка с кнопкой назад
  и заголовком «Saved states», список с собственной прокруткой.
- Строка: время сохранения, имя (карандаш → поле + ✓/✕), автор, кнопки
  **Load** (с подтверждением, если в черновике есть несохранённые правки) и
  **Make Release** (`Released` для уже опубликованного).
- Просмотр сохранения только для чтения (**View**) убран: у строки две
  названные кнопки. Скачивание ProjectFile сохранения тоже ушло из строки —
  маршрут и скачивание ProjectFile релиза остаются.

## Тесты и проверки

- REST: `TestLoadCommit_Project` (последнее сохранение → чистый Draft, стек
  очищен, 404), `TestLoadCommit_Library` (состав WidgetTypes, 404).
- UI: тесты панели (иконки вместо подписей), экрана истории, загрузки
  (последнее сохранение чисто, старое — с несохранёнными правками); тесты
  удалённых Discard/Revert/View переписаны на загрузку сохранения или удалены.
- Bruno: три новых запроса (2003–2005).
- `make build`, `make test`, `make bruno_test`, ручной проход в PWA.

## Comments

- **Домен не переименован.** `Commit` — это ~1200 идентификаторов, имена
  таблиц и колонок, контракт и коллекция Bruno; менять их вместе с новой
  панелью и экраном значило бы сделать один непроверяемый коммит. Решение:
  одно понятие — два имени, зафиксированные в `GLOSSARY.md`; полное
  переименование домена — отдельная задача, если понадобится.
- **Кнопки Load/Make Release — текстовые**, а не иконки: в списке из десятков
  строк подпись понятнее; панель режима — иконки, как просили.
