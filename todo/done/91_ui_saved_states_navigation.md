# UI: навигация до истории сохранения состояний

Status: ready-for-agent
Priority: 1

Панели Library и Project и строка навигации Root: путь до истории сохранений
и форма нового сохранения на её экране.

- **Имя сущности уходит из панели.** Между кнопкой назад и Save имени
  библиотеки или проекта больше нет: оно живёт в строке навигации.
- **Одна кнопка назад.** Стрелка панели — единственная: из истории сохранений
  она ведёт в редактор, из редактора — на страницу выбора. Экран истории
  собственной стрелки не рисует.
- **Отступ между назад и Save.** Кнопку назад и кнопку сохранения разделяет
  вертикальная линия.
- **Формы сохранения в панели нет.** Save (и Ctrl+S) открывает экран истории
  сохранений; сверху него — поле имени нового сохранения и кнопка Save. Автор
  берётся из имени пользователя (Misc → User name), отдельного поля нет.
- **Навигация — цепочка кнопок.** Режим, имя сущности и «Saved states» —
  отдельные кнопки; каждая ведёт на уровень выше: «Saved states» → имя
  сущности (редактор), имя → режим (страница выбора). Текущий шаг не ведёт
  никуда.
