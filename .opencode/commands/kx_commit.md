description: Собрать изменения в один коммит по правилам репозитория
---

Сделай коммит текущих изменений в этом репозитории.

Порядок:

1. Проверь ветку: `git branch --show-current`. Если это `path` — остановись и попроси переключиться на рабочую ветку (правило 1 AGENTS.md).
2. Разберись в изменении: `git status --short`, `git diff` и `git diff --cached`; посмотри стиль истории — `git log --oneline -10` и тела последних коммитов (`git log -3 --format='--- %h%n%B'`). Если менять нечего, скажи об этом и остановись.
3. Если менялся Go-код, прогони `make build` и `make test` (правило 3 AGENTS.md). Не проходят — не коммить, покажи ошибку.
4. Застейджи только то, что относится к изменению: `git add <пути>`. Не тащи в коммит посторонние правки, секреты, `bin/`, `.codegraph/` и локальные конфиги.
5. Сообщение — по-английски, как в истории: тема в императиве до 72 символов (`task NN_M: <что сделано>` для задачи из `todo/`, иначе короткое описание), пустая строка, затем тело — что и почему, без пересказа диффа по строкам. Никаких трейлеров вроде `Generated with` / `Co-Authored-By` и упоминаний ассистента.
6. Если тебе передали текст — $ARGUMENTS — возьми его за основу темы и тела.
7. Закоммить, затем покажи `git status --short` и `git log -1 --stat`. Не пушь: push — отдельное действие.
8. В конце отправь уведомление через ntfy по правилу 11 AGENTS.md.
