# Требования

## Основные требования

### Сервер

- Возможность работать в облаке
- Возможность работать в self-hosted варианте
- Интеграция с внешними системами аутентификации
- Поддержка различных протоколов устройств нижнего уровня
- Поддержка редактирования библиотек графических компонентов (нужно, чтобы была возможность разработки библиотек компонентов, которые бы хранились на сервере)
- Поддержка редактирования проектов (мнемосхемы и прочие настройки тоже хранились бы на сервере)

### Клиент

- Работа в браузере (в основных браузерах: Chromium, Firefox и т.д.)
- Несколько режимов работы (редактирование библиотеки, редактирование проекта, работа оператора)
- Аутентификация/авторизация через внешние системы
