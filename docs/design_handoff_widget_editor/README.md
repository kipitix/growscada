# Handoff: SCADA Widget Editor (вариант C · Focus)

## Overview
Окно редактирования библиотеки виджетов для SCADA-системы **GrowSCADA**. Инженер
выбирает тип виджета, правит HTML/SVG-шаблон его внешнего вида и JS-скрипт
обновления индикации, описывает входные порты (подключаемые переменные), задаёт
тестовые значения и сразу видит результат в живом превью.

Это редизайн существующего экрана: вместо плоской 6-колоночной «простыни» с
textarea — плотный IDE-подобный редактор с подсветкой синтаксиса, нумерацией
строк, тёмной и светлой темой и переключаемыми режимами раскладки кода.

## About the Design Files
Файлы в этом пакете — **дизайн-референс, сделанный в HTML/CSS/React**. Это
прототип, показывающий нужный внешний вид и поведение, **а не продакшн-код для
копирования**. React здесь использован только как удобный способ собрать
интерактивный макет.

Задача — **воссоздать этот дизайн в вашем стеке (Go + go-app**,
`github.com/maxence-charriere/go-app`). go-app прозрачно отражает сущности
веб-разработки: HTML-теги → методы билдера (`app.Div()`, `app.Button()`…),
атрибуты → `.Class()/.Style()/.Attr()`, события → `.OnClick()` и т.п. **CSS
переносится 1:1** — весь блок стилей ниже можно положить в статический `.css`
и подключить через `app.Handler{Styles: [...]}` без изменений.

См. `GO_APP_MAPPING.md` — там конкретные правила переноса HTML→go-app для этого
экрана и скелет компонента.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, состояния и
взаимодействия. Воссоздавайте пиксель-в-пиксель. Все CSS-переменные и значения
приведены ниже и в исходных файлах.

## Layout (общая структура)
Вертикальный флекс на весь вьюпорт:

```
┌─ ed-top (40px) ──────────────────────────────────────────────┐
│ tabs: Library/Project/Operation/History · spacer · brand · 🌗 │
├─ ed-body (flex:1, 6 колонок, разделители 1px) ────────────────┤
│ [Widget Types 224px] [Code flex:1.3] [Ports+Data 296px] [Preview flex:1.05] │
├─ statusbar (24px, фон = акцент) ──────────────────────────────┤
└───────────────────────────────────────────────────────────────┘
```
Колонки — `display:flex` с `gap:1px` на фоне `--border-soft` (тонкие
разделители-хейрлайны между панелями). Каждая панель — вертикальный флекс:
`panel-head` (шапка 34px) + `panel-body` (скролл) + опц. `panel-foot`.

### Колонка 1 — Widget Types (`flex:0 0 224px`)
- Шапка: иконка-куб + «Widget Types» + счётчик-бейдж + кнопка `+` (btn-accent).
- Список `witem`: иконка-плитка 26×26 + название + тип (`boolean/number/string`)
  моноширинным мелким. Активный пункт — фон `--accent-soft`, рамка `--accent-line`,
  иконка и тип окрашены в акцент.
- Футер: кнопка «Delete widget» (btn-ghost btn-danger, во всю ширину).

### Колонка 2 — Code (`flex:1.3 1 0`)
Шапка 40px. **Слева** — зависит от режима раскладки:
- режим `tabs`: сегмент-переключатель `Template / Script`;
- режимы `split-*`: заголовок «Template + Script».

**Справа (фиксированная позиция, не сдвигается при смене режима):**
1. `cmode` — группа из 3 иконок-кнопок: «Вкладки», «Тайлинг · скрипт сверху»,
   «Тайлинг · скрипт снизу».
2. **Apply** — `btn btn-accent btn-sm` с галочкой. **Всегда видна и всегда
   яркая** (важное требование — кнопка единого вида во всех местах экрана).

Тело:
- `tabs`: один CodeBlock (template.svg ИЛИ render.js).
- `split-st`: два тайла, скрипт сверху, шаблон снизу.
- `split-sb`: шаблон сверху, скрипт снизу.
- Тайлы разделены `cresize` (8px, `cursor:row-resize`) — перетаскиваемый
  разделитель, меняет соотношение высот (зажимается в 0.18…0.82).

**CodeBlock** = редактор кода только для чтения в макете: слева `code-gutter`
с номерами строк (sticky), справа `code-body` с подсветкой синтаксиса (см.
токены ниже). Моноширинный, 11.5px/1.65.

### Колонка 3 — Input Ports + Input Data (`flex:0 0 296px`)
Две секции в одной колонке:
- **Input Ports** (верх, `max-height:46%`): шапка + Apply (btn-accent). Список
  `port-row`: иконка-разъём (акцент) + имя порта (моно) + бейдж типа + описание +
  кнопка `×` (удалить). Внизу — «Add Port» (btn-sm, во всю ширину).
- **Input Data** (низ): шапка БЕЗ Apply — **данные применяются в реальном
  времени**. Список `data-row`: имя + бейдж типа + контрол ввода:
  - `boolean` → тумблер (toggle), вкл = зелёный `--ok`;
  - `number` → `input[type=number]`;
  - `string` → `input[type=text]`.
  Любое изменение мгновенно обновляет превью.

### Колонка 4 — Preview (`flex:1.05 1 0`)
- Шапка: глаз + «Preview» + бейдж «live».
- `preview-frame`: центрирование на фоне-сетке (22×22px grid из
  `--grid`-линий). В центре — `preview-card` 240×240 (скруглённая карточка
  `--bg-panel` с рамкой и тенью), внутри — отрендеренный виджет.
- `preview-meta` (низ): зелёная светящаяся точка + имя виджета + справа текущие
  значения портов (`state = true` …).

### Status bar (24px)
Фон = текущий акцент, текст белый, моноширинный 10.5px. Слева имя виджета +
режим; справа — кол-во связанных портов + индикатор «Live».

## Темы
Две темы, переключаются кнопкой 🌗 в правом верхнем углу (солнце/луна). Тема —
это класс на корне: `.theme-dark` / `.theme-light`, задающий набор
CSS-переменных. Менять только класс, вся палитра — в переменных.

## Акцент
Вариант C использует **teal** (`.acc-teal`). Акцент — отдельный класс с
переменными `--accent / --accent-soft / --accent-line`, тёплые токены кода
(строки/функции) дают тёпло-холодный баланс. Палитра поддерживает также
`.acc-blue` и `.acc-amber` (на случай тематизации).

## Interactions & Behavior
- **Выбор виджета** (клик по `witem`) → меняется активный, перезагружаются
  шаблон/скрипт/порты/данные/превью.
- **Переключатель темы** (🌗) → переключает класс `theme-dark`↔`theme-light`.
- **Режим раскладки кода** (3 иконки) → `tabs` / `split-st` / `split-sb`.
  Apply и группа режимов остаются на фиксированных позициях — layout не «прыгает».
- **Сегмент Template/Script** (только в `tabs`) → какой код показан.
- **Разделитель тайлов** (`cresize`, только в split) → drag по вертикали меняет
  соотношение высот панелей (0.18…0.82).
- **Input Data** → ввод/тумблер мгновенно (real-time, без Apply) пересчитывает
  входы и перерисовывает превью. Тумблер boolean: вкл = `--ok`.
- **Apply** (код, порты) → в проде: применить изменённый код/набор портов к
  прототипу. В макете — статичная, но визуально единая и всегда активная.
- **Add Port / × у порта / + и Delete виджета** → добавление/удаление (в макете
  кнопки присутствуют, логику реализовать в проде).
- **Hover**: кнопки/строки списков подсвечиваются `--hover`; `cresize` при
  наведении окрашивается в акцент.
- **Focus у input**: рамка `--accent` + кольцо `0 0 0 3px var(--accent-soft)`.

## State Management (минимум для прода)
- `theme: 'dark'|'light'`
- `accent: 'teal'` (расширяемо)
- `selectedWidgetId` → активный виджет
- `codeLayout: 'tabs'|'split-st'|'split-sb'`
- `codeTab: 'html'|'js'` (для режима tabs)
- `splitRatio: number` (0.18…0.82)
- `inputValues: map[widgetId]map[portName]rawString` — значения симулятора;
  при изменении приводятся к типу порта (`coerce`) и подаются в `render()`.
- Рендер превью: вставить `widget.template` в контейнер, затем вызвать
  пользовательский `render(el, inputs)` (в проде — безопасное выполнение
  скрипта виджета; в макете это JS-функция).

## Live preview — модель данных
Каждый виджет: `{ id, name, kind, template (HTML/SVG), script (текст render()),
ports:[{name,type,desc}], data:[{name,type,value}] }`. Входы строятся как
`coerce(type, rawValue)`: boolean←"true", number←parseFloat, string←as-is.
Три демо-виджета: Boolean Circle (SVG-круг меняет fill), Integer Speedometer
(стрелка+дуга+число), String Ticker (текст + цветная точка по содержимому).

## Assets
Иконки — инлайновые SVG (stroke-based, 24×24 viewBox, `stroke-width≈1.8`),
определены в `shared.jsx` (куб, активность, код, разъём, таблица, глаз, плюс,
корзина, галочка, ×, солнце, луна, поиск, шеврон, play). Внешних картинок и
шрифтов нет — только системные и моноширинный стек. Лого-плашка бренда —
CSS-градиент квадрат 18×18.
