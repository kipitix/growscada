# Domain Layer (`internal/server/domain/`)

> Architecture reference for the GrowSCADA server. `AGENTS.md` links here: read this
> document before changing the layer it describes. Decisions are in `docs/adr/`; the
> vocabulary is in `GLOSSARY.md`.

Each subdomain owns its aggregate, value objects, and repository **interface**:

| Package    | Aggregate / Concept |
|------------|---------------------|
| `project/` | `Project` — unit of isolation (ADR 0006): name unique among the live Projects of its Organization and an optional `Description` (≤500 characters, an attribute of the aggregate, never content); immutable (`Update` of name and description, `Delete` marks it deleted); `ProjectUpdatedEvent`; `ProjectEvent` (its own events) and `ContentEvent` (events of its Tags, Scenes, Widgets, which name the Project by embedding `project.Content`; no event is both) |
| `organization/` | `Organization` — identity marker of the tenant; the server runs with the one the migrations create |
| `tag/`     | `Tag` — the Tag definition (name, TagType, supplier) of one Project (`ProjectID`), an entity of its Draft, the Engineering node's; immutable (`Delete` returns a new Tag); `TagCreatedEvent`, `TagDeletedEvent`; the value objects both roles share (`TagName`, `TagType` with `ZeroValue`, `TagValue`, `TagQuality` — `Good/Bad/Uncertain`) |
| `tagstate/` | `TagState` — the Tag state (value, Quality, `Seq`) with its `Definition`'s copy, the Runtime node's (ADR 0011); immutable (`Write` returns a new one); `Initial` = the TagType's zero value with Quality `Bad`; `TagUpdatedEvent` (a `tag.TagEvent`, never stored in the outbox); `Repository` |
| `draft/`   | `Draft` — the working state of one Project or one Library, the unit of consistency of its content (ADR 0016, ADR 0017): its `Scope` (a Project's or a Library's, in this package), the one `Version` of its content and the `CleanVersion` — the Version at which the content last equalled its last Commit's (amendment 2026-11-10) — with `HasUnsavedChanges` (`Version` above `CleanVersion`), its `StackPosition`, and the operations over the content (`CreateTag`, `DeleteTag` unbinding Scenes, Scenes, Widgets, Devices, Environments, pairs, Library Imports, `Replace`, `Open`, `Purge`); `Draft.Undo`/`Draft.Redo` raise the Version and move the position, `draft.Session` is one write in the Draft's transaction (`Undo`/`Redo` apply a change's snapshots, never replay its operation), `draft.Snapshot` the before/after state of one touched entity, `draft.StackState` the two changes a client would undo and redo; `DraftChange` rows live in `engineering.draft_changes`. `draft.Commit` is the Draft's other entity (ADR 0021): an immutable, numbered snapshot of the whole Draft (the canonical ProjectFile or the Library's `WidgetTypeCopy` copies) with `CommitTitle` and `Author` VOs, its time and the Version it fixed; `WithTitle` records `commit_title_updated`, `NewCommit` `commit_created`; a Save writes no DraftChange, raises no Version and makes its Version the Clean Version, and `ErrNothingToSave` refuses a Draft at its Clean Version |
| `scene/`   | `Scene` — named canvas (mnemonic screen) of one Project, binding only Tags of it (`TagTypes` are read through the Project's scope, `ProjectScope.ProjectID`; TagTypes of another Project are `ErrTagTypesOfAnotherProject`, never taken for missing Tags); immutable aggregate whose methods (`AddWidget`, `UpdateWidget`, `MoveWidgets`, `RemoveWidget`, `Update`, `ReconcileWith`, `Delete`) return a new Scene; Scene and Widget events. `MoveWidgets` takes `WidgetMove` values (a Widget's ID and its new x/y), keeps every other field including z, reads neither the WidgetType nor the Tags (a broken binding never refuses a move, ADR 0010), records one `WidgetUpdatedEvent` per widget that actually moved and refuses a repeated ID (`ErrWidgetMovedTwice`), an unknown one (`ErrWidgetNotFound`) or a move that changes nothing (`ErrNothingToMove`) |
| `scene/`   | `Widget` — entity of the Scene aggregate: instance of a WidgetType placed on a Scene, with position/size/rotation/transform matrix |
| `library/` | `Library` — reusable collection of WidgetTypes of an Organization, outside every Project (ADR 0007): name unique among its live Libraries and an optional `Description` ; immutable (`Update` of name and description, `Delete` marks it deleted, refused while a live Project imports it or a running Deployment names a saved state of it); `LibraryEvent` (its own `library_created`/`library_updated`/`library_deleted`); its Draft is the `draft.Draft` of the Library (ADR 0016) |
| `library/` | `WidgetType` — entity of one Library's Draft (`LibraryID`, name unique in it): HTML template + JavaScript script, InputPorts; immutable, carries no Version of its own (`Update`, `Delete` — touches no Scene; `RecreateWidgetType` rebuilds the copies a Discard restores); its events name the Library. The reads are opened per Library (`WidgetTypeRepositories.ForLibrary`), the writes are the Draft's |
| `libraryimport/` | `LibraryImport` — the saved state (Commit) of one Library a Project's Draft uses (ADR 0007, ADR 0012), one per pair (`ContentEvent`); `Switch` with an expected Version, `Delete`; `ImportImpactOf` — the one function computing what a switch or removal does to the Project's Widgets (orphaned → refused, `OrphansError`; broken PortBindings → removed in the same DraftChange), used by the preview and the check; `libraryimport.Commit` values the saved state (its identity, number and the copies of its WidgetTypes) |
| `label/` | `Label` — a named mark with an optional color that an Engineer puts on saved states (ADR 0025), an aggregate of the Engineering node apart from the content and logically of the Organization (`OrganizationID`): `Name` (trimmed, 1–100 runes, one line, unique in the Organization ignoring case) and `Color` (`#RRGGBB` or empty, the theme's neutral one); its `Assignment`s are its entities (`Assign`, `Unassign`, idempotent, naming a `draft.Scope` and a Commit's number); events `label_created`, `label_updated`, `label_deleted`, `label_assigned`, `label_unassigned` go to the server's stream; `Delete` removes its assignments, and a Project's or a Library's deletion removes them through the database (the documented exception to ADR 0008) |
| `settings/` | `Settings` — the per-user settings of the server: one person's view of its content, the library and the project order for now (ADR 0024). An aggregate apart from the aggregates it names: a `Version`, an `Order` (weak references by ID, normalized), no event, no outbox. `SingleUser` owns them until Users and authentication exist |
| `event/`   | Base of domain events: `Event`, `Base`, `EventType` (every event name), `EventTimestamp`, `Recorder`. Imports no aggregate |
| `id/`      | Generic `ID[T]` UUID value object; type parameter prevents mixing IDs of different aggregates |
| `version/` | Optimistic-concurrency version value object; Generic `Version[T]` |
