# Live events are translated into the API contract, not named by the domain

Domain events (`internal/server/domain/event.EventType` and the event types of each aggregate) are the server's internal model; their names are also what the outbox codec stores, which is not a contract. The live events of the event stream (`GET /api/v0/events`) are part of the server API contract (ADR 0005): their type names are constants in `contract/api/v0`, and `restapi` translates each domain event into an `apiv0.Event` through one explicit table `event.EventType → apiv0` name, not through `EventType.String()`. A test fails if a domain event type has no translation or a contract constant is unused. We chose this over writing `String()` to the wire with a test that the two sets of names are equal (less code), because that would pin the domain's names as the published ones: renaming an event inside the server would silently change the API, and changing the API's name would change what the outbox stores. The domain does not import `contract/` (the dependency points inward). The table repeats today's names on purpose: they are the same now, but they are two languages, one internal and one published.
