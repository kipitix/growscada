# Devices deliver Tag values through one link contract

A Device (a simulator today, protocol adapters later) delivers Tag values to the server only through `internal/devicelink`: `Resolve` a Tag by its unique name (`GET /api/v0/tags?name=`, ADR 0003) and `Write` its value and Quality (`PATCH /api/v0/tags/{id}/value`). The link keeps each Tag's Version itself; on `409 Conflict` it rereads the Tag and retries once, because a Device is the source of truth for the values it reports and must not lose them to a concurrent write. A Tag deleted on the server (`404`) stops being written. Unreachable or failing servers (network errors, `5xx`) are transient: retried at startup, skipped until the next tick at runtime. Devices never create or delete Tags — that belongs to the Engineer's tools (`growctl`). We chose one Go contract over letting each adapter talk REST on its own so that the future Device aggregate, its tokens and any transport change land in one place; the device simulator is its first user and the reference for protocol adapters.

## Amendment 2026-10-04: Device is configuration, the Device Gateway is the process

The word "Device" above meant the delivering process. From now on (task 28, `CONTEXT.md`) a **Device** is configuration inside a Project: the equipment's address, protocol, connection parameters and how its Tags are extracted. That configuration is part of the Draft and the Revision. The process that executes it and talks this link contract is the **Device Gateway**, and the device simulator is the first one. A Gateway acts for a Device with a **Device Token** issued on the Runtime node. With that token it fetches the Device's configuration from the running Revision and may write only that Device's Tags; the Project is implied by the token. A token outlives Deploys and Rollbacks, is dormant (refused, not revoked) while the running Revision has no such Device, and ends only when it is explicitly revoked or rotated. A Tag has at most one supplying Device. The link's retry and conflict rules above are unchanged.
