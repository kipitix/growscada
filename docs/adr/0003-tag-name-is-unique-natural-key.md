# Tag name is a unique natural key

A Tag's name is unique within its Project (ADR 0006; until task 25 lands, within the single implicit project: a `UNIQUE` constraint on `tags.name`, a duplicate on create is reported as `409 Conflict`), and external tooling — `growctl` manifests, the device simulator — identifies Tags by name within a Project, never by UUID. We chose this over letting manifests carry client-assigned UUIDs because people and Devices naturally refer to process variables by name, manifests stay readable and portable between environments, and a non-unique name made name-based lookup (`GET /tags?name=`) ambiguous. The UUID remains the internal identity used by PortBindings and the REST resource paths.
